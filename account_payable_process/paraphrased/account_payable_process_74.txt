The following text is about the account payable process : it begins with file a copy for internal documents. Once a copy of internal records is made, you need to create a receipt report. When creating a receiving report is completed, one or more of the following paths should be executed: collecting the receiving report, confirming all documents have been amended, obtaining the vendor invoice. Once all documents have been updated, it needs to be reported to the relevant team member for errors. Then one or more of the following paths should be executed : the payment schedule, checking the deadlines to avoid penalty charges. Now the process is completed.
