The following description is about the account payable process, which starts with the sending to the receiving department. Once a transaction is sent to the receiving department, a receiving report should be created. When a receiving report is completed, one or more of the following paths should be executed: collecting invoice from vendors, double checking on a three-way match. Then the process is split into 3 parallel branches: scheduling the payment, storing invoice file and creating the voucher for the documents. When the payment is scheduled, the invoice should be entered into accounts payable. The process is now completed.
