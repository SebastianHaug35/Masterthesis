The following description is about the account payable process which begins when you send to the receiving department. When the sending to the receiving department is completed, then a receiving report should be created. Once the creating of a receiving report occurs, the next tasks should be to gather the receiving report and confirming that all documents have been modified. They should be done in parallel. When the receiving report is collected, reports should be made to the relevant team member. Once all pre-tasks are executed, one or more of the following paths should be executed: creating a voucher for the documents, storing in the invoice file The process is now done.
