The following description is about the account payable process and starts with filing a copy for internal records. When a copy of the internal records is completed you need to create a receiving report. Once a receiving report is created, one or more of the following routes should be executed : reporting errors to the relevant team member, double checking a three-way match. When reporting errors to the relevant team member is completed, it needs to be confirmed all documents have been amended. The process is then divided into 2 parallel branches: storing the invoice in paid file and scheduling the payment. The process is now completed.
