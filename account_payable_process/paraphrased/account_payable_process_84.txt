The following is about the purchase process, which starts when you enter the order details. Once the details of the purchase are entered you need to create a receiving report. Once a receiving report occurs, the next tasks should be doubling a three-way match and collecting the receiving report. This should be done in parallel. When the doubling check is completed a three-way match, confirming all the documents have been amended must be done After all pre-tasks are completed, then data checks should be done to avoid penalties. The process is now finished.
