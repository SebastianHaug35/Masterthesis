The following is about the account payable process, which starts when you send them to the vendor accounting department. When a send is completed to the vendor accounting department, you need to create a receiving report. When creating a receiving report is completed, the process is divided into 3 parallel branches: confirmation all documents have been amended, gathering the receiving report and doubling check a three-way match. Once all pre-tasks have been executed, stamping must be done on all documents. The process is now completed.
