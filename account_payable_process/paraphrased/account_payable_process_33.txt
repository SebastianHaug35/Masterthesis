The text below is about the Account Receivable process, which starts when you send to the receiving department. Once the sender passes to the receiving department, you must create a receiving report. When a receiving report creation is completed one or more of the following paths should be executed: Reporting errors to the relevant team member, doubling a three-way match. Then one or more of the following paths should be executed: scheduling the payment, checking the dates to avoid penalty charges. After checking dates to avoid penalties, one or more of the following paths should be performed: creating vouchers for the documents, stamping all documents. The process is now finished.
