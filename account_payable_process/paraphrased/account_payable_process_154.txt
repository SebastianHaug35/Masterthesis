The following text is about the account payable process, which starts with sending to the receiving department. When sending the receipt department is completed, you need to create a receiving report. When the creating of a receiving report is completed, one or more of the following paths should be executed : collecting the vendor invoice, reporting errors to the relevant team member, doubling a three-way match. After that the next tasks should be to record the invoice file and create a voucher for the documents. It should be completed in parallel. Once the creation of the voucher for the documents takes place, one or more of the following paths should be executed: Entering the invoice into the accounts payable account, Terminating the payment. The process is now completed.
