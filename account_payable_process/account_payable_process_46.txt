The text below is about the account payable process. It begins when you send to the vendor accounting department. When sending to the vendor accounting department is completed, creating a receiving report needs to be done. When creating a receiving report is completed, you need to double check a three-way match. When doubling check a three-way match is completed, the next tasks should be storing in paid invoice file and scheduling the payment, they should be done in parallel. The process is now completed.
