The text below is about the account payable process. It starts with sending to the receiving department. When sending to the receiving department is completed, creating a receiving report should be done. When creating a receiving report is completed, the process is split into 2 parallel branches: gathering the receiving report and confirming all documents have been amended. When gathering the receiving report is completed, the next tasks should be gathering the vendors invoice and doubling check a three-way match, they should be done in parallel. When gathering the vendors invoice is completed, you need to report errors to relevant team member. Once all pre-tasks are executed, then you need to create voucher for the documents. The process is now completed.
