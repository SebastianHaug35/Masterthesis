The following description is about the account payable process. It begins when you send to the receiving department. After sending to the receiving department, you need to create a receiving report. Once creating a receiving report occurs, gathering the vendors invoice needs to be done. Once gathering the vendors invoice occurs, the next tasks should be storing in paid invoice file and scheduling the payment, they should be done in parallel. Once scheduling the payment occurs, the next tasks should be creating voucher for the documents and checking dates to avoid penalty charges, they should be done in parallel. The process is now completed.
