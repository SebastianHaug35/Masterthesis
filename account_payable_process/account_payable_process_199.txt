The following text is about the account payable process. It starts with sending to the receiving department. When sending to the receiving department is completed, creating a receiving report needs to be done. When creating a receiving report is completed, the process is split into 2 parallel branches: confirming all documents have been amended and gathering the vendors invoice. After gathering the vendors invoice, doubling check a three-way match needs to be done. Once all pre-tasks are executed, then one or more of the following paths should be executed: creating voucher for the documents, entering the invoice into the accounts payable account. After creating voucher for the documents, you need to check dates to avoid penalty charges. The process is now completed.
