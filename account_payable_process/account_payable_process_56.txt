The text below is about the account payable process. It starts with entering purchase order details. Once entering purchase order details occurs, creating a receiving report needs to be done. When creating a receiving report is completed, one or more of the following paths should be executed: doubling check a three-way match, reporting errors to relevant team member. After reporting errors to relevant team member, the next tasks should be gathering the receiving report and confirming all documents have been amended, they should be done in parallel. Afterwards, you need to check dates to avoid penalty charges. The process is now completed.
