The following text is about the account payable process. It starts with entering purchase order details. After entering purchase order details, creating a receiving report needs to be done. When creating a receiving report is completed, the next tasks should be confirming all documents have been amended and gathering the receiving report, they should be done in parallel. After confirming all documents have been amended, the next tasks should be doubling check a three-way match and gathering the vendors invoice, they should be done in parallel. Once all pre-tasks are executed, then stamping all documents should be done. The process is now completed.
