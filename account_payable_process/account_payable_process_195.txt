The text below is about the account payable process. It starts with entering purchase order details. When entering purchase order details is completed, creating a receiving report should be done. When creating a receiving report is completed, the next tasks should be gathering the vendors invoice and confirming all documents have been amended, they should be done in parallel. After confirming all documents have been amended, the next tasks should be gathering the receiving report, doubling check a three-way match and reporting errors to relevant team member, they should be done in parallel. Once all pre-tasks are executed, then the next tasks should be creating voucher for the documents and checking dates to avoid penalty charges, they should be done in parallel. The process is now completed.
