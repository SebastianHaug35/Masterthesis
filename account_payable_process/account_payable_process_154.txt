The following text is about the account payable process. It starts with sending to the receiving department. When sending to the receiving department is completed, you need to create a receiving report. When creating a receiving report is completed, one or more of the following paths should be executed: gathering the vendors invoice, reporting errors to relevant team member, doubling check a three-way match. After that, the next tasks should be storing in paid invoice file and creating voucher for the documents, they should be done in parallel. Once creating voucher for the documents occurs, one or more of the following paths should be executed: entering the invoice into the accounts payable account, scheduling the payment. The process is now completed.
