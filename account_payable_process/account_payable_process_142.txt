The text below is about the account payable process. It begins when you file a copy for internal records. Once filing a copy for internal records occurs, you need to create a receiving report. Once creating a receiving report occurs, gathering the receiving report should be done. Once gathering the receiving report occurs, the process is split into 2 parallel branches: creating voucher for the documents and checking dates to avoid penalty charges. When creating voucher for the documents is completed, the next tasks should be stamping all documents, storing in paid invoice file and entering the invoice into the accounts payable account, they should be done in parallel. Once checking dates to avoid penalty charges occurs, you need to schedule the payment. The process is now completed.
