The following description is about the account payable process. It begins when you send to the receiving department. After sending to the receiving department, creating a receiving report should be done. After creating a receiving report, doubling check a three-way match needs to be done. When doubling check a three-way match is completed, the process is split into 3 parallel branches: creating voucher for the documents, storing in paid invoice file and entering the invoice into the accounts payable account. The process is now completed.
