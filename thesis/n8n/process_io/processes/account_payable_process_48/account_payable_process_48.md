# account payable process 48  ## Source Description  The following description is about the account payable process, which begins when you send to the Receiving department. Once the sending occurs to the receiving department, you must create a receipt report. When the creation of a receiving report is completed, confirmation should be done that all documents have been amended. After all documents have been amended, one or more of the following paths should be executed: checking the dates to avoid penalty charges, scheduling the payment. The process is now completed.  ## Artifacts  - `account_payable_process_48.gv` - `account_payable_process_48.pdf`
