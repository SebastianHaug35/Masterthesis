# account payable process 183  ## Source Description  The following text is about the account payable process. It begins with the entry of purchase order details. When the purchase order field is completed, you need to create a receiver report. When a receiving report is created one or more of the following paths should be executed: reporting errors to the relevant team member; acquiring the vendors invoice. The next tasks should then be storing in paid invoice file and rescheduling the payment. They should be done in parallel. The process is now completed.  ## Artifacts  - `account_payable_process_183.gv` - `account_payable_process_183.pdf`
