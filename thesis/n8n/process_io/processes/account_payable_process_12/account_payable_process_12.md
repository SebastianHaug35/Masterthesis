# account payable process 12  ## Source Description  The following text is about the credit card process : it starts when you send the receiving department to an account. Once sending occurs to the receiving department, you need to create a Receiving Report. When creating a receiving report is completed, one or more of the following paths should be executed: collecting the receiving report, gathering the vendor invoice. The process is then divided into 3 parallel branches: stamped all documents, checking dates to avoid penalty charges, and the processing of payments. The process has now been completed.  ## Artifacts  - `account_payable_process_12.gv` - `account_payable_process_12.pdf`
