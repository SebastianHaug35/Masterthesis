# account payable process 26  ## Source Description  The following text is about the account payable process. It starts with filing a copy for internal records. When a copy for internal records is completed, creating a receiving report needs to be done. After creating a receipt report, you need to confirm that all documents have been amended. When all documents have been amended, you must arrange the payment. The process is now complete.  ## Artifacts  - `account_payable_process_26.gv` - `account_payable_process_26.pdf`
