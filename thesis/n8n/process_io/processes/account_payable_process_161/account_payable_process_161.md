# account payable process 161  ## Source Description  The following is a description of the Account payable Process, which begins when you send to the Receiving department. Once sending occurs to the receiving department, you need to create a receipt report. When the creation of a receiving report is completed, the process is divided into 2 parallel branches : the receiving report and the vendor invoice. After gathering the receipt report, you need to double check a three-way match. Once all pre-tasks are executed, one or more of the following paths should be executed: storing in a paid invoice file, creating voucher for the documents The process is now complete.  ## Artifacts  - `account_payable_process_161.gv` - `account_payable_process_161.pdf`
