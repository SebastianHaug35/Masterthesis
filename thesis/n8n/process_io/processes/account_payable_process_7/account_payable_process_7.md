# account payable process 7  ## Source Description  The following text is about the account payable process that begins when you file a copy for internal records. When filing a copy for internal records is completed, create a receiving report. Once a receiving report is created, the vendor invoice needs to be submitted. When the order for the vendor invoice is completed the process is split into 2 parallel branches: entry of the invoice into the account payable and calendar of payment. The process is now completed.  ## Artifacts  - `account_payable_process_7.gv` - `account_payable_process_7.pdf`
