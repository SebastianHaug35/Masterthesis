# account payable process 99  ## Source Description  The following is a description of the account payable process : It starts with the payment details. After entering the purchase order details, the sending report should be created. Once creating a receiving report is completed, the process is split into 2 parallel branches : confirming that all documents have been amended and reporting errors to the relevant team member. Once all pre-tasks are executed then one or more of the following routes should be executed: scheduling payment, stamping all documents. The process is now completed.  ## Artifacts  - `account_payable_process_99.gv` - `account_payable_process_99.pdf`
