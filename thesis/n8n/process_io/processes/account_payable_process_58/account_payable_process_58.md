# account payable process 58  ## Source Description  The following text is about the account payable process. It starts when you send an envelope to the senior accountant in your department. Once a request for a submission to the senior accountant in your department occurs, a receipt should be created. After creating a receiving report, gathering needs to be done. After gathering the receiving report, the next tasks should be to check the dates to avoid penalty charges and schedule the payment, these should be done in parallel. The process is now complete.  ## Artifacts  - `account_payable_process_58.gv` - `account_payable_process_58.pdf`
