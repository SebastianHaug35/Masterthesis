# account payable process 148  ## Source Description  The text below is about the account payable process and starts with receipt to the vendor accounting department. When a submittal is completed to the vendor accounting department, you need to create a receiving report. Once a receiving report appears, the gather the vendor's invoice needs to be done. Once the vendor bill comes to a conclusion, you need to create a voucher for the documents.
