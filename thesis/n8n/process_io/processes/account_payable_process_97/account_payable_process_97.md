# account payable process 97  ## Source Description  The text below is about the payment process which starts with sending to the sending department. When the sending of the receiving department is completed, then a receipt report must be done. Once a receiving report exists, you need to report the errors to the appropriate team member. After reporting errors to the relevant team member, the next task should be checking dates to avoid penalties and entering the invoice into the accounts payable account, they should be done in parallel. After putting the invoice in the account payable, one or more of the following paths should be executed : i.e. ; stamping all documents; scheduling the payment. The process is now complete.  ## Artifacts  - `account_payable_process_97.gv` - `account_payable_process_97.pdf`
