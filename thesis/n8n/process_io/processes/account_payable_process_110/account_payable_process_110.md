# account payable process 110  ## Source Description  The following text is about the account payable process which begins when you send to the receiving department. When sending to the receiving department is completed, creating a receiving report should be done. Once a receiving report is created, one or more of the following paths should be executed : collecting the vendors invoice, reporting errors to the relevant team member. After that, you need to enter the invoice into the account payable. The process is now completed.  ## Artifacts  - `account_payable_process_110.gv` - `account_payable_process_110.pdf`
