# account payable process 157  ## Source Description  The following text is about the payment process, which starts when you enter the details of your purchase order. When the purchase order data entry is completed, you need to create a receiving report. When creating a receiving report is completed the next task should be confirming that all documents have been amended and gathering the receiving report, which should be done in parallel. Once all pre-tasks are completed, stamping should be completed on all documents. The process is now finished.  ## Artifacts  - `account_payable_process_157.gv` - `account_payable_process_157.pdf`
