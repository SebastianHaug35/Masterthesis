# account payable process 81  ## Source Description  The text below is about the account payable process that starts with filing a copy of the internal records. Once the copy filing for internal records occurs, a receipt report should be created. Once creation of a receipt report occurs, one or more of the following pathes should be executed: gathering the receipt report, gathering the vendor invoice. After collecting the receiving report, the process is split into 2 parallel branches : reporting error to the relevant team member and doubling check a three-way match. The next tasks should subsequently be adding the invoice into the accounts payable account, scheduling the payment and creating the documents vouchers. Once the invoice is entered into the credit card account, stamping should be done for all documents. The process is now completed.  ## Artifacts  - `account_payable_process_81.gv` - `account_payable_process_81.pdf`
