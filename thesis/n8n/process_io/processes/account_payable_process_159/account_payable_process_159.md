# account payable process 159  ## Source Description  The following description is about the accounting payable process, which starts when you send invoices to the vendor accountancy department. Once the send is reported to the vendor accounting department, a receiving report should be created. Once a receiving report is created, the receiving report needs to be gathered. Once the collection of the receiving report has occurred, the stamping should be done on all documents. The process is now completed.  ## Artifacts  - `account_payable_process_159.gv` - `account_payable_process_159.pdf`
