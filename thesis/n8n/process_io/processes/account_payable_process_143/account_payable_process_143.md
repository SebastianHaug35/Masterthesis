# account payable process 143  ## Source Description  The following description is about the Account payable process which starts with the sending to the receiving department. When a sending to the receiving department is completed, a receiving report needs to be created. When a receiving report is created, the next tasks should be verifying that all documents have been modified and double check a three-way match, and that they should be done parallel to this. Once all pre-tasks are completed, the process is split into 2 parallel branches: creating the vouchers and storing them in the paid invoice file. Once a voucher creation occurs for the documents, one or more of the following paths should be executed : - Posting all documents ; - Schedule the payment. After planning the payment, the invoice should be entered into the Accounts payable. After recording in paid invoice file, a check should be done to avoid penalties. The process is completed now.  ## Artifacts  - `account_payable_process_143.gv` - `account_payable_process_143.pdf`
