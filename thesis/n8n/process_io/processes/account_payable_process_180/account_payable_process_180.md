# account payable process 180  ## Source Description  The following description is about the account payable process, which begins when you send to the vendor accounting department. After sending to the vendor accounting department, a receiving report should be created. Once creation of a receiving report occurs, one or more of the following paths should be executed: doubling checking a three-way match, collecting the vendor invoice, and confirming all documents have been modified. The next task should be storing in paid invoice file and entering in the account payable. They should be done in parallel. The process is now completed.  ## Artifacts  - `account_payable_process_180.gv` - `account_payable_process_180.pdf`
