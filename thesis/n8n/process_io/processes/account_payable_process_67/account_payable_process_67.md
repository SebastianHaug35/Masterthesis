# account payable process 67  ## Source Description  The following description is about the accounts payable process - it begins with filing a copy for internal records. After filing a copy for internal records, a receiving report should be created. When creating a receiving report is completed, you need to confirm that all documents have been modified. Once the amended documents have confirmed, the process is split into 2 parallel branches: Creating a voucher for the documents and checking date to avoid penalty charges. The process is now finished.  ## Artifacts  - `account_payable_process_67.gv` - `account_payable_process_67.pdf`
