# account payable process 187  ## Source Description  The following description is about the accounts payable process, which begins with submitting a copy for internal records. After filing a copy for internal records, create a receiving report should be done. When a receiving report is completed, one or more of the following paths should be executed: acquiring the vendor invoice, reporting errors to the relevant team member. After reporting errors to the relevant team member, doubling check a three-way match should be done. Afterwards, you need to enter the invoice into the payable account. The process is now complete.  ## Artifacts  - `account_payable_process_187.gv` - `account_payable_process_187.pdf`
