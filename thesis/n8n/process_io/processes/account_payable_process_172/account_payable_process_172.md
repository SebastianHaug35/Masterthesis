# account payable process 172  ## Source Description  The following text is about the account payable process: it begins when you send the mail to the receiving department. When the send to the receiving department is completed, you need to create a receiving report. After creating a receiving report, it needs to report errors to the relevant team member. When reporting errors is completed to the relevant team member, one or more of the following paths should be executed: stamping all documents, and storing in paid invoice file. When the recording in the paid invoice file is completed, scheduling the payment should be done. The process is now complete.  ## Artifacts  - `account_payable_process_172.gv` - `account_payable_process_172.pdf`
