# account payable process 106  ## Source Description  The above text is about the account payable process, which starts with the sending of the letters to the receiving department. Create a receipt report after sending to the receiving department. Once a receiving report is created, one or more of the following paths should be executed: gathering the receiving report, doubling a three way match. Then, the invoice should be entered in the payables account. The process is now completed.  ## Artifacts  - `account_payable_process_106.gv` - `account_payable_process_106.pdf`
