# account payable process 115  ## Source Description  The following description is about the cashier - process which begins when you send to the receiving department. Once the sending of an email to the receiving department is completed, a receiving report should be created. When a receiving report is completed, the gathering of the receiving report must be done. After gathering the Receiving Report, the next tasks should be storing in a paid invoice file and stamping all documents. They should be done in parallel Once a payment is captured in the paid invoice file, the next tasks should be entering the invoice into the accounts payable and the payment - scheduling, they should be done in parallel. The process is now completed.  ## Artifacts  - `account_payable_process_115.gv` - `account_payable_process_115.pdf`
