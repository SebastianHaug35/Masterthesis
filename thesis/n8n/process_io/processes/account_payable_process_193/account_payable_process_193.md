# account payable process 193  ## Source Description  The following description is about the Account payable process and begins when you send the senior accountant in your department. Once a formal report to the senior accountant in your department appears, it needs to be done. Once a receiving report is created, the process is divided into two parallel branches: gathering the receiving report and gathering the vendor invoice. After acquiring the receiving report, a three-way match should be checked by the double check. Once all pre-tasks are executed, then creating a voucher for the documents should be done. The process is now completed.  ## Artifacts  - `account_payable_process_193.gv` - `account_payable_process_193.pdf`
