# account payable process 141  ## Source Description  The following description describes the process of bringing a balance to the department you sent it to. After sending to the receiving department, creating a receiving report should be done. After generating a receiving report, the process is divided into 2 parallel branches: submitting errors to the relevant team member and verifying that all documents have been modified. When all documents have been completed and there are now documents to check, you need to get the receiving report. Once all pre-tasks are executed, then checking of dates must be done to avoid penalty charges. The process is now completed.  ## Artifacts  - `account_payable_process_141.gv` - `account_payable_process_141.pdf`
