# account payable process 4  ## Source Description  The text below is about the account payable process that starts when you send the senior accountant in your department. Once the sending occurs to the senior accountant in your department, then a receiving report must be done. After creating a receiving report, one or more of the following paths should be executed : Double check a three-way match, confirm all documents have been amended, reporting errors to the relevant team member. Then, it is necessary to create a voucher for the documents. The process is now complete.  ## Artifacts  - `account_payable_process_4.gv` - `account_payable_process_4.pdf`
