# account payable process 43  ## Source Description  The below text is about the account payable process and starts with the purchase order details. Once the Purchase Order details are entered, a receiving report should be created. When the creation of a receiving report is completed, one or more of the following paths should be executed: gathering the receiving report, double checking a three-way match, reporting errors to the relevant team member. When collecting the receive report is completed, the next task should be gathering the vendor's invoice and confirming all documents have been amended, this should be done in parallel. Finally, the date verification to avoid penalties is required. Now the process has concluded.  ## Artifacts  - `account_payable_process_43.gv` - `account_payable_process_43.pdf`
