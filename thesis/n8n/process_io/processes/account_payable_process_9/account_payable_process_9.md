# account payable process 9  ## Source Description  The following description is about the account payable process, which starts with sending to the receiving department. Once the sending department is launched, a receiving report should be generated. Once a receipt reports is created, all documents must be amended. When confirmation that all documents have been amended is completed, one or more of the following paths should be completed: creating a voucher for the documents, checking dates to avoid penalties. After checking the dates to avoid unforeseen penalties, the invoice is entered into the accounts payable account. Now the process is completed.  ## Artifacts  - `account_payable_process_9.gv` - `account_payable_process_9.pdf`
