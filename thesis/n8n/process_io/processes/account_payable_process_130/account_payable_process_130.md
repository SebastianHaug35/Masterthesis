# account payable process 130  ## Source Description  The following description is about the account payable process and starts with sending the senior accountant in your department. After delivering a deposit to a senior accountant in your department, you should create a receiving report. After creating a receipt report, one or more of the following paths should be executed: Double Check a three-way match, collecting the receiving report. When a three-way match is completed on a doubling check, one or more of the following paths should be executed : gathering the vendors invoice and confirming that all documents have been modified. After that, scheduling must be completed the payment. The process is now completed.  ## Artifacts  - `account_payable_process_130.gv` - `account_payable_process_130.pdf`
