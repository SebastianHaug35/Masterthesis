# account payable process 197  ## Source Description  The text below is about the account payable process which begins when you send to the receiving department. After sending to the recipient department, a receiving report should be created. When a receiving report is completed, one or more of the following paths should be executed: submitting errors to the relevant team member, confirming all documents have been amended, double-checking a three-way match. Afterwards, the amount should be scheduled. The process is now complete.  ## Artifacts  - `account_payable_process_197.gv` - `account_payable_process_197.pdf`
