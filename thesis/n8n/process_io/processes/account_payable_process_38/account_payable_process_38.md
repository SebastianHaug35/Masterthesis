# account payable process 38  ## Source Description  The following text is about the account payable process, which starts when you send to the receiving department. When the sending is completed to the receiving department, a receiving report needs to be created. Once a Receiver Report exists, the vendors should pay invoices. When the vendor's invoice is created, stamping should be done all documents. The process has now been completed.  ## Artifacts  - `account_payable_process_38.gv` - `account_payable_process_38.pdf`
