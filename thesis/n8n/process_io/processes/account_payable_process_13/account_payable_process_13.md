# account payable process 13  ## Source Description  The following description is about the account payable process that begins with the filing of a copy for internal records. When a copy is filed for internal records, you need to create a receiving report. After creating a receiving report, one or more of the following paths should be executed: - Reporting errors to the relevant team member confirming that all documents have been amended. - The next tasks should be entering the invoice in the accounts payable account and storing in the paid invoice file. They should be done in parallel. The process is now complete.  ## Artifacts  - `account_payable_process_13.gv` - `account_payable_process_13.pdf`
