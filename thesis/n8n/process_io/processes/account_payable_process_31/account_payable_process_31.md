# account payable process 31  ## Source Description  The text below is about the account payable process that starts with sending the vendor accounting department. Once the sending happens to the vendor accounting department, a receiving report needs to be created. After creating a receiving report, a three-way match should be performed by doubling check. When a three-way match has been completed, you need to schedule the payment. The process is now complete.  ## Artifacts  - `account_payable_process_31.gv` - `account_payable_process_31.pdf`
