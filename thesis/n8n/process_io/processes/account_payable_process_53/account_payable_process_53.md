# account payable process 53  ## Source Description  The text below is about the account payable process that begins when you send to the receiving department. Once the sending occurs to the receiving department, you need to create a receiving report. When the creation of a receiving report is completed, the process is divided into 3 parallel branches : Double check a three-way match, Gathering the vendor invoice and confirming that all documents have been amended. After collecting the vendors invoice, the receiving report should be done. Once all documents have been amended, reporting errors should be done to the appropriate team member. Once all pre-projects are executed, then you need to schedule the payment. The process is now completed.  ## Artifacts  - `account_payable_process_53.gv` - `account_payable_process_53.pdf`
