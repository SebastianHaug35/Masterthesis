# account payable process 101  ## Source Description  The text below is about the account payable process that begins when you email to the vendor's accounting department. Once the sending to the vendor accounting department occurs, creating a receiving report should be made. Once creation of a receiving report occurs, one or more of the following path should be executed: confirming all documents have been amended, reporting error to the relevant team member. After confirming all documents have been amended, the double check should do a three-way match. Afterwards, checking of dates to avoid penalty fees must be done. The process is now complete.  ## Artifacts  - `account_payable_process_101.gv` - `account_payable_process_101.pdf`
