# account payable process 129  ## Source Description  The following text is about the account payable process that starts with sending to the vendor accounting department. Once the sending to the vendor accounting department occurs, you must create a receiving report. When a receiving report is completed, the next tasks should be reporting errors to the relevant team member and collecting the receiving report. Once all pre-requisites are executed, then you need to stamp all documents. The process is now finished.  ## Artifacts  - `account_payable_process_129.gv` - `account_payable_process_129.pdf`
