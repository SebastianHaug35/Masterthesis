# account payable process 120  ## Source Description  The following text is about the account payable process and starts when you send to the receiving department. When sending to the receiving department is completed, creating a receiving report must be done. Once a receipt is created the process is divided into 3 parallel branches : doubling a three way match and confirming all documents have been changed and gathering the vendor invoice. After the acquisition of the vendor invoice is completed, the receipt report should be done. After all pretasks are completed, one or more of the following should be executed: scheduling the payment, stamping all documents. After setting the payment the dates should be checked to avoid penalties. The process is now completed.  ## Artifacts  - `account_payable_process_120.gv` - `account_payable_process_120.pdf`
