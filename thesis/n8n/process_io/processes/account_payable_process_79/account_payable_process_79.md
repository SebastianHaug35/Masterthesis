# account payable process 79  ## Source Description  The following text is about the account payable process; it starts with the details of the purchase order. After entering the purchase order details, a receiving report has to be created. When a receiving report is completed, one or more of the following paths should be executed : reporting errors to the relevant team member, doubling a three-way match. Once an error report occurs to the appropriate team member, it has to be confirmed that all documents have been amended. Then you need to archive the file in the paid invoice The process is now complete.  ## Artifacts  - `account_payable_process_79.gv` - `account_payable_process_79.pdf`
