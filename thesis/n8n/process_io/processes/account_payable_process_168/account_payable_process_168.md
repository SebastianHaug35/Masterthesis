# account payable process 168  ## Source Description  The following description is about the account payable process, which begins when you file a copy for internal records. When a copy of internal records is filed, you need to create a receiving report. Once a receiving report was created, one or more of the following paths should be executed: creating the receiving report and confirming that all documents have been amended. Afterwards, you have to schedule the payment. The process is now completed.  ## Artifacts  - `account_payable_process_168.gv` - `account_payable_process_168.pdf`
