# account payable process 45  ## Source Description  The following description is about the account payable process, it begins when you send the notification to the receiving department. When the sending to the receiving department is completed, creating a receiving report should be done. After creating a receiving report the next tasks should be gathering the vendor invoice, confirming that all documents have been amended and reporting errors to the relevant team member. It should be done in parallel. After checking that all documents have been amended, you should double check a three-way match. After reporting errors to the relevant team member, gathering should be done the receiving report. Once all pre-tasks are executed, then checking dates should be done to avoid penalty charges. The process is now done.  ## Artifacts  - `account_payable_process_45.gv` - `account_payable_process_45.pdf`
