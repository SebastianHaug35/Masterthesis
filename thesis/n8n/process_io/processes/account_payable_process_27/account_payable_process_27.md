# account payable process 27  ## Source Description  The following description is about the account payable process, which begins when you file a copy for internal records. When a copy of a paper form is completed for internal records, a receipt report needs to be created. Once a receiving report is created, a report to the relevant team member needs to be done. When reporting errors to the relevant team member is completed, you must enter the invoice into the Accounts payable account. The process is now complete.  ## Artifacts  - `account_payable_process_27.gv` - `account_payable_process_27.pdf`
