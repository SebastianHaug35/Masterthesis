# account payable process 174  ## Source Description  The below text is about the account payable process. It starts when you send the vendor accounting department. After you send the vendor accounting department, you must create a receiving report. When creating a receipt report is completed, it needs to confirm that all documents have been amended. After confirming that all documents have been amended, a or more of the following paths should be executed: creating a voucher for the documents, stamping all documents.
