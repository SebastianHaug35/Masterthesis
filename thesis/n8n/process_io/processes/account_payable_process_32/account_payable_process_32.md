# account payable process 32  ## Source Description  The following description is about the account payable process and starts with sending it to the senior accountant in your department. When sending to the senior accountant in your department is completed, a receiving report should be generated. Once creation of the receiving report occurs, one or more of the following paths should be executed : reporting errors to relevant team member, confirming that all documents have been amended. During confirmation all documents have been amended a three-way match should be double checked. Afterwards, one or more of the following paths should be executed: the storing of invoice in the paid file, the creation of the voucher for documents. Once storing of paid invoice file occurs, one or more of the following paths should be executed: entering the invoice in the accounts payable account, stamping all documents. The process is now done.  ## Artifacts  - `account_payable_process_32.gv` - `account_payable_process_32.pdf`
