# account payable process 196  ## Source Description  The following is about the account payable process. It begins when you send your invoice to the vendor accounting department. When the invoice sent to the vendor accounting department is completed, a receiving report needs to be created. Once a receipt report is created, capturing the receipt report should be done. After collecting the receiving report, the next task should be coordinating the payment and stamping all documents. These should be done in parallel. The process is now finished.  ## Artifacts  - `account_payable_process_196.gv` - `account_payable_process_196.pdf`
