# account payable process 39  ## Source Description  The following text is about the account payable process, which begins with the sending to the senior accountant in your department. When a sms to the senior accountant in your department is completed, creating a sms report should be done. After creating a receiving report the next task should be reporting the errors to the relevant team member and collecting the vendor invoice. These should be done in parallel. Once all the pre-tasks have been completed the payment should be scheduled. The process is now concluded.  ## Artifacts  - `account_payable_process_39.gv` - `account_payable_process_39.pdf`
