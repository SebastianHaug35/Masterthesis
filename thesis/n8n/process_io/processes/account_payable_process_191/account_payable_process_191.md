# account payable process 191  ## Source Description  The text below is about the accounts payable process. It begins when you send it to the Senior Accountant in your department. After sending to the senior accountant in your department, you will need to create a receiving report. When creating a receiving report is completed, confirming that all documents have been amended should be done. After verifying that all documents have been amended, the invoice should be entered into the accounts payable account. The process is now finished.  ## Artifacts  - `account_payable_process_191.gv` - `account_payable_process_191.pdf`
