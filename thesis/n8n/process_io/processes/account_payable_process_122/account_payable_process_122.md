# account payable process 122  ## Source Description  The following description is about the account payable process and starts with the mailing to the receiving department. Once the sending to the receiving department occurs, creating a receipt report needs to be done. After creating a receiving report, the process is split into 2 parallel branches: reporting errors to the relevant team member and double checking a three-way match. Once all pre-tasks are executed then the next tasks should be creating a voucher for the documents, storing the invoice in paid invoice file and entering the invoice in the accounts payable account. They should be done in parallel. When the creation of the voucher for the documents is completed, the process is split into two parallel branches : checking the dates to avoid penalty charges and arranging the payment. The process is now finished.  ## Artifacts  - `account_payable_process_122.gv` - `account_payable_process_122.pdf`
