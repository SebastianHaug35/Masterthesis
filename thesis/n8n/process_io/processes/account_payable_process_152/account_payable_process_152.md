# account payable process 152  ## Source Description  The text below is about the account payable process which begins when you send to the receiving department. When sending to the recipient department is done, a receiving report should be created. When creation of a receiving report is completed, the report should be done to the relevant team member. Once reporting errors to the relevant team member occurs, creating a voucher for the documents must be completed. The process is now completed.  ## Artifacts  - `account_payable_process_152.gv` - `account_payable_process_152.pdf`
