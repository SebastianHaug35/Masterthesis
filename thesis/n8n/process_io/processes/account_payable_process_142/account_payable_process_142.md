# account payable process 142  ## Source Description  The following text is about the payables process which begins when you file a copy for internal records. Once a copy of internal records is filed, you need to create a receiving report. Once a receiving report occurs, the receiving report should be collected. Once the receiving report is formed, the process is split into 2 parallel branches : creating voucher for the documents and checking dates to avoid penalty charges. When the creating of the voucher is completed the next task should be tampering all documents, storing the invoice in the payable account and adding the invoice in parallel. Once Checking Dates To Avoid Penal Charges occurs, you need to schedule the payment. Now the process is complete.  ## Artifacts  - `account_payable_process_142.gv` - `account_payable_process_142.pdf`
