# account payable process 73  ## Source Description  The following description is about the invoice process and commences when you send the senior accountant in your department. After sending to the senior accountant in your department, creating a receiving report needs to be done. After creating a receiving report, it needs to confirm that all documents have been modified. Once confirming all documents are amended, you should stamp all documents. The process is now completed.  ## Artifacts  - `account_payable_process_73.gv` - `account_payable_process_73.pdf`
