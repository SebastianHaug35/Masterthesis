# account payable process 163  ## Source Description  The text below is about the account payable process which starts with directing to the vendor billing department. After sending an invoice to the vendor accounting department, you need to create a receiving report. When the creation of a receiving report is completed, the receipting of the vendors invoice must be done. When the list of vendors is completed, you need to stamp all documents. The process is now finished.  ## Artifacts  - `account_payable_process_163.gv` - `account_payable_process_163.pdf`
