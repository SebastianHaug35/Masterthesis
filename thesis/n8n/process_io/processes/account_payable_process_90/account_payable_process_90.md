# account payable process 90  ## Source Description  The text below is about the account payable process which starts with the entering of the order details. After entering the purchase order information, a receiving report needs to be created. Once a receiving report appears, the collect of the vendor invoice should be done. Once collecting the invoice of the vendors occurs, one or more of the following paths should be executed : creating vouchers for the documents, checking date to avoid penalty charges, storing in paid invoice file. The process is now complete.  ## Artifacts  - `account_payable_process_90.gv` - `account_payable_process_90.pdf`
