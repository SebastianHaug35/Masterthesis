# account payable process 175  ## Source Description  The text below is about the account payable process: it starts with sending to vendor accounting department. When the processing of sending to the vendor accounting department is completed, you need to create a receipt report. When a receiving report is completed you must check a three-way match twice. After doubling a three-way match, you need to schedule the payment. The process is now complete.  ## Artifacts  - `account_payable_process_175.gv` - `account_payable_process_175.pdf`
