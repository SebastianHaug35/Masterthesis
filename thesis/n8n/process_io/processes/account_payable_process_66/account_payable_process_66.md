# account payable process 66  ## Source Description  The following text is about the Account payable process, starting with a purchase order detail. After entering the Purchase Order Details, a receiving report should be created. Once a Receiver Report is created, the next tasks should be to confirm that all documents have been amended and to report errors to the relevant team member. The reports should be done in parallel. Once all of the pre-tasks have been completed, storing in paid invoice file needs to be done. The process is now completed.  ## Artifacts  - `account_payable_process_66.gv` - `account_payable_process_66.pdf`
