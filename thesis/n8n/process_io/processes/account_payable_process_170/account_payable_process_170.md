# account payable process 170  ## Source Description  The following description is about the account payable process, which starts when you file a copy for internal documents. Once a copy of a document appears for internal records, it should be done creating a receiving report. Once a receiving report is created, one or more of the following paths should be executed: doubling a three-way match, confirming all documents are amended and gathering the receiving report. After confirmation that all documents have been amended, one or more of the following paths should be executed: reporting the errors to the relevant team member, gathering the vendor invoice. The next tasks should then be checking dates to avoid penalty charges and scheduling the payment - they should be done in parallel. When the checking of dates is completed to avoid penalty charges, one or more of the following paths should be executed: depositing in the invoice file, entering the invoice into the accounts payable account. The process is now complete.  ## Artifacts  - `account_payable_process_170.gv` - `account_payable_process_170.pdf`
