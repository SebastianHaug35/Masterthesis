# account payable process 91  ## Source Description  The following description is about the account payable process. It begins when you submit to the vendor accounting department. When the transfer to the vendor accounting department is complete, a Receiving Report must be created. After creating a receiving report, the process is split into 2 parallel branches : reporting errors to the relevant team member and doubling a three-way match. Once the problem has been reported to a member of the relevant team, you need to confirm that all documents have been amended. Once all pre-tasks have been completed, then you must check the dates to avoid penalties. The process is now complete.  ## Artifacts  - `account_payable_process_91.gv` - `account_payable_process_91.pdf`
