# account payable process 56  ## Source Description  The text below is about the Account payable Process and begins with the entry of the Order Order Details. Once the purchase order is entered, a receipt report has to be created. When the creation of a receiving report is completed, one or more of the following paths should be executed: Double checking a three-way match, reporting errors to the relevant team member. After the reported errors to the relevant team member, the next tasks should be collecting the receiving report and confirming that all documents are amended, they should be done in parallel. After registering your dates you will need to check them to avoid penalty charges. The process is now complete.  ## Artifacts  - `account_payable_process_56.gv` - `account_payable_process_56.pdf`
