# account payable process 149  ## Source Description  The following text is about the account payable process which starts with sending to the receiving department. When the sending to the receiving department is completed, a receiving report needs to be created. After generating a receive report, gather the receipt report. Once the receiving report gathering occurs, one or more of the following paths should be executed: the scheduling of payments, creation of a voucher for the documents. Once the payment is scheduled, stamping should be done of all documents. The process is now completed.  ## Artifacts  - `account_payable_process_149.gv` - `account_payable_process_149.pdf`
