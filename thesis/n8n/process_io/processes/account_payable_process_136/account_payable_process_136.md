# account payable process 136  ## Source Description  The text below is about the accounts payable process, which starts with the sending department. Once sending to the receiving department occurs, creating a receiving report should be done. When the creation of a receiving report occurs, you need to report errors to the relevant team member. After reporting errors to the relevant team member, one or more of the following paths should be executed : entering the invoice into the Accounts Receivable Account, payment scheduling. The process is now concluded.  ## Artifacts  - `account_payable_process_136.gv` - `account_payable_process_136.pdf`
