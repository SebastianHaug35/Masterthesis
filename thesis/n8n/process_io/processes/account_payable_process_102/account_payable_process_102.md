# account payable process 102  ## Source Description  The following text is about the invoice process and starts with the receipt department. When the sending to the receiving department is completed, you need to create a receiving report. Once a receiving report is created, it should be done confirming that all documents are amended. When it has been confirmed that all documents have been amended, it should be scheduled the payment. The process is now completed.  ## Artifacts  - `account_payable_process_102.gv` - `account_payable_process_102.pdf`
