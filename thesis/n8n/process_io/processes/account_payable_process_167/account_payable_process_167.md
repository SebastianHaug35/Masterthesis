# account payable process 167  ## Source Description  The below text is about the payable process that begins when you enter the order details. Once purchase order details appear, creating a receiving report must be done. When creating a Receiving Report is completed, you must confirm that all the documents have been changed. Once all documents have been altered, you need to enter the invoice in the Accounts payable account. The process is now completed.  ## Artifacts  - `account_payable_process_167.gv` - `account_payable_process_167.pdf`
