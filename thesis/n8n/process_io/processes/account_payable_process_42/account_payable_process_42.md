# account payable process 42  ## Source Description  The following text is about the Account payable process, which starts when you send it to the vendor account department. A receipt report should be created after sending it to the vendor accounting department. When a receiving report is created, you need to collect vendors invoices. When the vendors invoice is collected, if payment schedule, the payment should be done. The process is now finished.  ## Artifacts  - `account_payable_process_42.gv` - `account_payable_process_42.pdf`
