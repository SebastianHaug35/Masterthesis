# account payable process 140  ## Source Description  The text below is about the account payable process - it starts when you file a copy for internal records. When filing a copy for internal records is completed, a receiving report must be generated. When a receiving report is completed, collecting the vendor invoice should be done. When collecting the vendors' invoice is done, storing needs to be done in the payment invoice file. The process has now been concluded.  ## Artifacts  - `account_payable_process_140.gv` - `account_payable_process_140.pdf`
