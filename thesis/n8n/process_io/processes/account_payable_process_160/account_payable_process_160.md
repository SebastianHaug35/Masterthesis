# account payable process 160  ## Source Description  The text below is about the payable process that starts with the send to the senior accountant in your department. Once sending to the senior accountant in your department happens, creating a receiving report has to be done. Once the creation of a receiving report occurs, collecting the receiving report must be done. When gathering the receiving report is complete, creating vouchers for the documents must be done. The process is now completed.  ## Artifacts  - `account_payable_process_160.gv` - `account_payable_process_160.pdf`
