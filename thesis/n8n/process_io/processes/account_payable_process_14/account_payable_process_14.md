# account payable process 14  ## Source Description  The text below is about the Account payable process, which begins when you send to the senior accountant in your department. Once the sending occurs to the senior accountant in your department, you need to create a receiving report. When creating a receiving report is completed, one or more of the following paths should be run : gathering the receiving report, gathering vendors invoice, reporting errors to the relevant team member. When gathering the receiving report is completed, one or more of the following paths should be executed: doubling check a three-way match confirming all documents have been amended. Then you need to schedule the payment. The process is now finished.  ## Artifacts  - `account_payable_process_14.gv` - `account_payable_process_14.pdf`
