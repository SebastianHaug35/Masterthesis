# account payable process 190  ## Source Description  The following text is about the payable process. It starts when you send the receiving department. Once sending to the receiving department happens, you will need to create a receiving report. When the creating of a receiving report is completed, one or more of the following paths should be executed: Gathering the vendor invoice, Gathering the receiving report. After that, storing to be done in the paid invoice file. The process is now completed.  ## Artifacts  - `account_payable_process_190.gv` - `account_payable_process_190.pdf`
