# account payable process 85  ## Source Description  The following text is about the account payable process, starting with the sending to the vendor accounting department. Once a payment occurs to the vendor accounting department, a receiving report needs to be created. After creating a receipt report, you need to gather the receiving report. After gathering the receiving report, there is to be created a voucher for the documents. The process is now complete.  ## Artifacts  - `account_payable_process_85.gv` - `account_payable_process_85.pdf`
