# account payable process 181  ## Source Description  The following is about the account payable process, which begins when you send the senior accountant in your department. After sending to the senior accountant in your department, a receiving report should be created. After creating a receiving report, the next tasks should be doubling check a three-way match and reporting errors to the relevant team member. They should be done in parallel. When the reporting of errors to the appropriate team member is completed, one or more of the following paths should be executed : confirming all documents have been amended, gathering the vendor invoice, and obtaining the receive's report '. Once all pre-tasks are executed, one or more of the following paths should be executed : creating vouchers for the documents, entering the invoice into the accounts payable account. The process is now complete.  ## Artifacts  - `account_payable_process_181.gv` - `account_payable_process_181.pdf`
