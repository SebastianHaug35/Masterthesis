# account payable process 23  ## Source Description  The following text is about the account payable process and starts with filing a copy for internal records. Once a copy of the record is filed for internal records, you need to create a receiving report. When the creation of the Receiving report is completed, one or more of the following paths should be executed: confirming that all documents have been changed, doubling check a three-way match, gathering the Receiving Report After doubling a three-way match, a timely report of errors is to be made to the relevant team member. Then one or more of the following paths should be executed: creating vouchers for the documents, stamping all documents. The process is now complete.  ## Artifacts  - `account_payable_process_23.gv` - `account_payable_process_23.pdf`
