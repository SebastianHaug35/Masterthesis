# account payable process 105  ## Source Description  The following text is about the account payable process. It starts by entering purchase order details. After entering purchase order details, a receipt report should be produced. After creating a receipt report, a three-way match is needed to be doubled check. After double checking a three-way match the process is split into 3 parallel branches: storing in the paid invoice file, creating the voucher for the documents and stamping all documents. The process is now finished.  ## Artifacts  - `account_payable_process_105.gv` - `account_payable_process_105.pdf`
