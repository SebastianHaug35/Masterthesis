# account payable process 88  ## Source Description  The following is about the account payable process - beginning with putting down the purchase order details. After entering the purchase order details, creating a receiving report must be done. Once creating a receiving report is completed, the next task is to confirm that all documents have been amended and gather the receiving report in parallel. After confirming all documents have been amended, the next task is doubling a Three-Way Match and gathering the vendors invoice, these should be done parallel. Once all pre-tasks are executed, then it is time to stamp all documents. The process is now completed.  ## Artifacts  - `account_payable_process_88.gv` - `account_payable_process_88.pdf`
