# account payable process 199  ## Source Description  The following text is about the account payable process, which starts with sending to the receiving department. When the sending of an invoice to the receiving department is completed, a receiving report is to be created. When creating a receipt report is completed, the process is split into two parallel branches : verifying that all documents have been amended and the gathering of the vendor invoice. After gathering the vendor invoice, doubling checks a three-way match needs to be done. Once all pre-actions are executed, one or more of the following paths should be executed: creating voucher for the documents, entering invoice in the accounts payable account. After creating the voucher for the documents, you must check the dates to avoid penalties. The process is now completed.  ## Artifacts  - `account_payable_process_199.gv` - `account_payable_process_199.pdf`
